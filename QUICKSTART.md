# Quick Start Guide

Get the Time Tracker running in 5 minutes!

## Step 1: Start Backend

```bash
cd backend
npm install
npm run dev
```

You should see: `Server running on port 5000`

## Step 2: Start Frontend (in another terminal)

```bash
cd frontend
npm install
npm run dev
```

You should see: `Local: http://localhost:5173`

## Step 3: Open in Browser

Visit `http://localhost:5173` and login with:
- Name: Your name
- Email: any email

## Step 4: Try It Out

- Click **Clock In** to start
- Click **Clock Out** when done
- View **Weekly** tab for summaries
- View **History** tab for all entries

That's it! The app stores data in memory for now.
